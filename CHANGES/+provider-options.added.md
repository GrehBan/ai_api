`client.generation.with_options({...})` returns a copy of the resource that sends a provider's own fields with every request, fields the shared request does not hold: `store`, `previous_response_id`, `temperature` and `top_p` for OpenAI (`OpenAIGenerationOptions`), `stop_sequences` for Anthropic (`AnthropicGenerationOptions`). The options are a `TypedDict` of the client's provider, so a wrong key or value is a type error; at run time an unknown key raises `RequestValidationError` at once and an invalid value before anything is sent. Code typed as `IGenerationClient` has no `with_options`.
