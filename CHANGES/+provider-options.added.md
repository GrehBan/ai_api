`client.generation.create()` and `stream()` take `provider_options=`, a provider's own fields of that call that the shared request does not hold: `store`, `previous_response_id`, `temperature` and `top_p` for OpenAI (`OpenAIGenerationOptions`), `stop_sequences` for Anthropic (`AnthropicGenerationOptions`). The options are a `TypedDict` of the client's provider, so a wrong key or value is a type error; at run time an unknown key or an invalid value raises `RequestValidationError` before anything is sent. Code typed as `IGenerationClient` cannot pass them.
