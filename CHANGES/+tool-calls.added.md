`GenerationResponse.tool_calls` and `CompletedEvent.tool_calls` list the model's calls of the request's tools as `ToolCall`s (`id`, `name`, `arguments` as JSON text; `parse_arguments()` gives the object and raises `ValueError` for text that is not one), from OpenAI's `function_call` items and Anthropic's `tool_use` blocks, buffered or streamed. `output_text`/`reasoning_summary`/`tool_calls` (OpenAI) and `message_text`/`message_thinking`/`message_tool_calls` (Anthropic) do the same for the providers' own responses.
