**Breaking:** a provider client declares its shared resources with `bind_resource`: `generation = bind_resource(GenerationResource[Response, ResponseStreamEvent], MyGenerationAdapter)`, with `adapter_factory=` for an adapter that takes options from the client. `BaseProviderClient` builds every adapter before the session (a bad option still fails without one) and every resource after it, and checks each adapter's provider when the class is defined. `adapter_types` and `BaseProviderClient.adapter()` are removed.
