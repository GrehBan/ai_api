`GenerationRequest` and `client.generation.create()` / `stream()` take `tools` (a list of `Tool`: name, description, JSON Schema `parameters`, `strict`), `tool_choice` (a `ToolChoice`: `AUTO`, `NONE`, `REQUIRED`, or a `ForcedTool` naming one tool) and `parallel_tool_calls`, sent to OpenAI as function tools and to Anthropic as custom tools; settings no provider takes (a choice without tools, a forced tool that is not one of them, duplicate names, parallel calls with `NONE`) are refused before sending. OpenAI's provider options gain `include` and `max_tool_calls`.
