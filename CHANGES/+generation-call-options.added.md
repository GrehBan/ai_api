`client.generation.create()` and `stream()` take the options of the call, `headers=`, `timeout=` and `retry_policy=`, as `send_request` does, and pass them to the session unchanged for every provider: an idempotency key, a longer limit for one generation or a single attempt no longer needs the provider's own methods. The use cases of `aiollm.resources` pass them on too, and `aiollm.session.CallOptions` names them for `**options`.
