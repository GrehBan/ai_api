**Breaking:** `Turn` has a `type` field (`"text"`), which shows in its `repr` and `model_dump()`; a dict without `type` still reads as a `Turn`. `GenerationResponse.to_turn()` returns `Turn | ToolCallTurn` and raises `ValueError` for a response with calls that stopped early. The adapters' `input_conversion` takes a list of `InputItem`s instead of `Turn`s, so a custom conversion handles the new items; `GenerationRequest.input` and the `input` of `create()` / `stream()` are typed `str | Sequence[InputItem]`, so a `list[Turn]` still type-checks. `ToolCall` moved to `aiollm.types.requests` (it is still in `aiollm`).
