**Breaking:** `GenerationResource` takes the provider's options as its third type parameter, `GenerationResource[RawT, RawItemT, OptionsT = NoProviderOptions, SessionT = ISession]`, so a session type given as the third argument moves to the fourth. Its adapter is an `IGenerationAdapter`, which adds `with_options(options, /) -> Self` to `ICompositeAdapter`: a generation adapter of your own without provider options adds `def with_options(self, options: NoProviderOptions, /) -> Self: return self`. `CallOptions` is now closed (PEP 728): a `**options: Unpack[CallOptions]` takes no other key, and `typing-extensions` is a direct dependency.
