**Breaking:** `GenerationRequest.metadata` is replaced by `end_user_id`, an opaque id of the end user (a hash, never personal data) that both providers use to detect abuse: OpenAI's `safety_identifier` (up to 128 characters, now a field of `CreateResponse`) and Anthropic's `metadata.user_id` (up to 512). The shared `metadata` meant different things (free-form pairs stored by OpenAI, only `user_id` at Anthropic). Pass `end_user_id=...` where you passed `metadata={"user_id": ...}`, and OpenAI's free-form pairs as `provider_options={"metadata": {...}}` (`OpenAIGenerationOptions`).
