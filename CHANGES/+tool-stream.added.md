`client.generation.stream()` yields `ToolCallStartEvent` (`call_id`, `name`), `ToolCallDeltaEvent` (a piece of the arguments) and `ToolCallDoneEvent` (the whole `ToolCall`, before the response ends) for each tool call, from OpenAI's function call items and Anthropic's `tool_use` blocks. `CompletedEvent` carries `native`, the stream's own output put together from its events (Anthropic's thinking with its signature among it), and `to_turn()`, so a streamed tool loop continues as a buffered one does.
